# Model-72 for Schwung

**The CA-72 circuit-modelled 1970s monosynth as a [Schwung](https://github.com/charlesvestal/schwung) sound generator for
Ableton Move.**

This is the Move edition of [Model-72](https://github.com/sd88me/mpc-vst-model72), the MPC/Force plugin that ports
[**CA-72**](https://github.com/idlefoundry/ca-72), Idle Foundry's open-source model of the Minimoog Model D. It is the same
engine (`engine/`, a pinned copy), with no skin: its panel is laid out as Move's knob pages.

## Pages

The root page is the preset browser (Init and CA-72's 19 factory sounds); its knobs are Cutoff, Emphasis, Contour Amount,
Filter Decay, Loudness Decay, Glide, Mod Wheel and Volume. Click in for the eight pages:

| Page | Knobs 1-8 |
|---|---|
| **Oscillators** | Osc 1 Range · Osc 1 Wave · Osc 2 Range · Osc 2 Wave · Osc 2 Freq · Osc 3 Range · Osc 3 Wave · Osc 3 Freq |
| **Mixer** | Osc 1 · Osc 2 · Osc 3 · Noise · Patch (Ext In) · Noise Type · Drive · Bass Comp |
| **Filter** | Cutoff · Emphasis · Contour Amount · Attack · Decay · Sustain · Filter Mode · Filter Mod |
| **Loudness** | Attack · Decay · Sustain · Volume · Level · Auto Gain, and the Auto Gain dB readout |
| **Controller** | Tune · Glide · Glide Switch · Decay Switch · A-440 · Kbd Control 1 · Kbd Control 2 |
| **Modulation** | Mod Mix · Osc Mod · Osc 3 Control · Mod Wheel · Bend Range · AT > Mod |
| **Voice** | Quality (LO / HI) · Mode · Voices · Entropy · Note Priority · Retrigger |
| **Stereo** | Width · Inner · Detune · Played As · Placement |

Every switch is an enum (Off / On, or its named positions).

## How the panel differs from the MPC plugin

- **No source switches.** OSC 1, 2, 3 and NOISE play while their volume is above 0 (at 0 the plugin switches them off, as
  the panel's switch would, so they cost nothing).
- **PATCH is always wired.** The output is cabled into EXTERNAL INPUT, and the Patch (Ext In) volume is the amount: 0 is
  unpatched. EXTERNAL INPUT has no other audio (on the MPC neither).
- **AT > Mod.** Pad pressure (polyphonic or channel aftertouch) turns the modulation wheel; the higher of the pressure and
  CC 1 wins, and the Mod Wheel knob adds as before. Move has no wheels; pitch bend and CC 1 come in over USB MIDI.
- **Presets** are converted: a switched-off source comes in at volume 0, and EXT volume is 0 unless the sound used PATCH
  (Feedback Funk does).
- Dropped: the skin, the STEREO tab's live field, MAIN OUT (always on).

## Quality

**LO** is CA-72's light voice, MONO / POLY (2-10) / UNISON. **HI** is one voice through the circuit's own transistor
ladder (see the MPC plugin's README for the measurements). HI's filter is built on a background thread when the module
loads; until it is ready HI plays the light filter. HI costs 30-55 % of a Force core; on Move it has yet to be measured.

## Building and installing

```
scripts/test.sh                 # contract checks + a host simulation under ASan/UBSan (x86, Docker for the Rust engine)
scripts/build.sh                # aarch64 build -> build/model-72-module.tar.gz
scripts/deploy.sh [host] [--reboot]   # install on a Move (default move.local); a new dsp.so needs a reboot
```

The engine is developed in mpc-vst-model72; `scripts/sync_engine.sh [../mpc-vst-model72]` refreshes `engine/`, and
`scripts/check_engine.sh` (run by `test.sh`) fails on a hand edit. The pages, names and presets are generated by
`tools/gen_schwung.py`.
